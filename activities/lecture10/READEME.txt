## Regex Used

First Name (letters, optionally a single middle name, case-insensitive):

`^[A-Za-z]+( [A-Za-z]+)?$`

Last Name (letters, apostrophes ', hyphens -):

`^[A-Za-z]+(['\-][A-Za-z]+)*$`

Email (traditional format, TLD 2–6 characters):

`^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,6}$`

Password (≥12 characters, 1 uppercase, 1 lowercase, 1 number, 1 special character):

`^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[^A-Za-z0-9]).{12,}$`

## Reflection

I found this activity to be a bit challenging, especially when getting the expressions to work properly.

The most helpful part of the process was using an external tool. I found the site regex101.com to be practically useful. It allows you to enter your regular expression and a list of test cases right below it. This makes it super easy to see in real-time which cases are passing or failing, which saved a lot of time and helped me fix mistakes quickly.
